# commit-helper

**Propose un message de commit propre à partir de tes fichiers modifiés.**

Zéro dépendance · Node.js 18+ · Windows, macOS, Linux.

## Utiliser tout de suite (sans rien installer)

```bash
npx github:zrk-lol/commit-helper
```

## Installer la commande `commit-helper`

```bash
npm install -g github:zrk-lol/commit-helper
commit-helper
```
